# 더미 실적 데이터(6000행) 생성 계획서

## 배경/동기
사용자가 제공한 `2026년 07월 3. 손익분석 (1단계 작업용)_더미더미.xlsb`(Desktop)는 "실적 Raw Data" 시트 1개만 담긴 축소 템플릿이다(1행 안내문구, 2행 "계획" 가이드 행, 3행 헤더, 4~6행 예시 데이터 3건, 141개 컬럼). 앱의 업로드·집계·이상징후 기능을 대량 데이터로 테스트/데모하기 위해 이 템플릿 구조를 기준으로 약 6000행 규모의 더미 실적 데이터를 생성한다.

## 범위
- 대상: "실적 Raw Data" 시트 포맷만 재현한다(이 더미 파일에는 실적 Re-arrange용 수식 시트·제품분류 매핑 시트가 없으므로 제외).
- 1~3행(안내문구/계획 가이드/헤더)은 원본 그대로 보존한다.
- 4행부터 데이터 행을 채워 **총 데이터 행 6000건**(기존 예시 3건 포함, 신규 5997건 생성)이 되도록 한다.
- 컬럼 순서·개수(141개)는 원본과 동일하게 유지한다.

## 방법
- **식별자 컬럼(상품/고객/손익센터/기간·연도/납품처)**: 원본 예시의 "코드+설명" 패턴을 유지하며, 상품·고객·납품처는 재사용 가능한 풀(수십~수백 개)에서 뽑아 배정한다. 손익센터는 `.docs/03_데이터정제.md` §4.1에서 확인된 4개 분기(20342/20345/20313/기타)로 분산 배정하고, 기간/연도는 최근 1~2년 12개월에 걸쳐 분산해 추이·이상징후 테스트가 가능하게 한다.
- **금액/수량 컬럼(136개)**: 원본 예시 데이터 3건 중 하나를 템플릿으로 선택해 컬럼 전체를 동일한 랜덤 배율로 선형 스케일링한다. 이렇게 하면 컬럼 간 합산·일치 관계(예: 매출액(Total)=매출액, 원재료비 합계=세부 5개 항목 합)가 예시 데이터에 이미 성립해 있던 그대로 보존된다. 매출수량은 상품코드가 `R` 또는 `QZZ`로 시작하면 0으로 강제하는 예외(`.docs/03_데이터정제.md` §4.6 근거)를 반영한다.
- **출력 형식**: `.xlsb`는 pyxlsb가 읽기 전용이라 파이썬에서 쓸 수 없으므로(`.docs/04_기술스택.md` 근거), 앱이 지원하는 형식 중 하나인 `.xlsx`로 저장한다(`backend/app/services/validation.py` 허용 확장자: xlsx/xls/xlsb/csv).
- 저장 위치: 원본 파일과 동일한 위치(Desktop)에 별도 파일명(`..._더미6000행.xlsx`)으로 저장해 원본은 건드리지 않는다.

## 완료 기준
- 생성된 파일을 pandas로 재로딩했을 때 데이터 행 수 6000, 컬럼 수 141이 확인된다.
- 헤더 행·컬럼 순서가 원본과 동일하다.
- 주요 컬럼(매출액·매출원가·판관비 등)의 값이 음수 매출 등 비현실적 이상값 없이 합리적 범위에 분포한다.
- 원본 `.xlsb` 파일은 수정하지 않는다(읽기만 수행).
