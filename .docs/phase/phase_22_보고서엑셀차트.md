# Phase 22 작업 계획서 — F7 보고서 초안 엑셀 다운로드에 팀별 추이 차트 포함

- 근거: 사용자 요청(원문) — "보고서 초안 자동생성에서, 엑셀 다운로드 시 내용에 그래프도 같이 들어가게."

## 배경/동기

`app/services/export.py`의 `build_report_workbook()`은 지금 "팀/제품군/판정기준/코멘트/배경 설명" 컬럼만 있는 표 1개짜리 시트다. F7 화면(`app/reports/page.tsx`)은 각 팀 섹션에 `GET /batches/{id}/trend`를 재사용한 매출액(Bar)+영업이익(Line) 추이 차트를 보여주는데, 엑셀로 내려받으면 이 시각 자료가 빠진다. 사용자는 다운로드한 엑셀 파일을 회의체/임원 메일에 그대로 첨부하는 것을 전제로 하므로(PRD F9), 화면에서 보던 차트가 엑셀에도 그대로 있어야 한다.

## 범위

**구현**:
1. `app/services/export.py`의 `build_report_workbook()`이 보고서 초안에 등장하는(제외되지 않은 항목 기준) 팀 목록을 모아, 각 팀에 대해 `analytics.get_trend(db, team, year, month)`(F4/F7 화면이 이미 쓰는 것과 동일한 함수)를 호출해 12개월 데이터를 가져온다.
2. 워크북에 시트 2개를 추가한다 — "차트데이터"(숨김, 팀별 12개월 월/매출액/영업이익 표)와 "추이 차트"(화면용, 팀마다 매출액(막대)+영업이익(선, 보조축) 콤보 차트 하나씩 세로로 배치). openpyxl의 `BarChart`+`LineChart` 조합(`bar += line`, `line.y_axis.crosses = "max"`)으로 F7 화면의 ComposedChart와 같은 모양(막대=매출액, 선=영업이익, 축 분리)을 재현한다.
3. 기존 "보고서 초안" 표 시트는 그대로 둔다(하위 호환 — 기존에 이 파일을 열어보던 방식이 그대로 동작).

**범위 밖**:
- 제품군별/거래처별 세부 차트는 추가하지 않는다(F7 화면 자체가 팀 단위 추이만 보여주므로 그대로 반영).
- 차트 스타일(색상 등)은 openpyxl 기본값을 쓴다 — Overview PDF처럼 SEBANG 디자인 토큰을 정교하게 맞추는 작업은 하지 않는다(엑셀 네이티브 차트라 임의 커스터마이징 여지가 제한적이고, 사용자 요청은 "그래프가 들어가게"이지 특정 디자인 재현이 아님).

## 방법·완료 기준

- 보고서 초안에 항목이 있는 각 팀마다 "추이 차트" 시트에 콤보 차트가 하나씩 생긴다(팀이 하나도 없으면 이 두 시트 자체를 만들지 않는다).
- "차트데이터" 시트의 숫자가 `GET /batches/{id}/trend`가 반환하는 값과 일치한다(데이터가 없는 달은 빈 셀로 남아 화면과 동일하게 "값 없음"으로 표시된다).
- xlsx를 다시 열었을 때(openpyxl `load_workbook`) 차트 객체가 실제로 포함돼 있는지 회귀 테스트로 확인한다.
- 백엔드 전체 pytest 통과. 프론트 변경 없음(다운로드 링크는 이미 있는 것을 그대로 씀).
