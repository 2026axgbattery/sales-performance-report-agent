# Phase 20 작업 계획서 — "누계평균대비" 폐지, "단가변동"에 전월·누계 통합 비교로 흡수

- 근거: 사용자 요청(원문) — "누계 평균대비는 별도의 버튼으로 분류하지 말고, 단가 변동탭에서 XX팀, XX제품군 - 당월 평균단가 XX원, 전월 XX원 (XX원, XX% 차이), 누계평균 XX원 (XX원 XX% 차이) 이런식으로 당월 평균단가와 전월, 누계를 한꺼번에 비교하게만 해줘. 단가 변동에서만 비교해보자."

## 배경/동기

Phase 17에서 신설한 "누계평균대비"(METRIC_CUMULATIVE_AVG)는 팀×제품군의 **매출액**을 연초~직전월 평균과 비교하는 별도의 F3 판단 기준이었다. 사용자는 이를 독립된 기준(F5의 별도 버튼)으로 유지하는 대신, **평균단가**(기존 "단가변동" 기준)에 한해 전월 대비와 누계평균 대비를 한 판정·한 문장으로 합쳐서 보여주길 원한다. 즉:
- "누계평균대비"라는 F3 기준/F5 버튼 자체를 없앤다(매출액 누계평균 비교는 더 이상 하지 않는다).
- "단가변동"은 이제 평균단가를 두 기준(전월/누계평균) 모두와 비교하고, 둘 중 하나라도 임계치를 넘으면 플래그하되, 화면에는 항상 전월·누계 두 비교를 함께 보여준다.

## 범위

**구현**:
1. `app/services/thresholds.py`: `METRIC_CUMULATIVE_AVG` 제거(`ALL_METRICS`/`DEFAULTS`에서 삭제). `seed_default_thresholds`에 `ALL_METRICS`에 없는 기존 `threshold_config` 행을 정리하는 로직을 추가한다(기존 로컬 DB에 이미 시딩된 "누계평균대비" 행이 고아로 남지 않도록 — `COLUMN_MIGRATIONS`와 같은 취지의 전방 호환 정리).
2. `app/services/anomaly.py`:
   - "3. 누계평균 대비" 패스를 완전히 제거한다.
   - "5. 평균단가 변동률"을 확장한다 — 전월 대비(기존)와 누계평균 대비(신규, 평균단가 기준)를 모두 계산하고, **둘 중 하나라도** 기존 단가변동 임계치(기본 5%)를 넘으면 플래그한다(두 비교에 별도 임계치를 새로 만들지 않는다 — F6 설정을 늘리지 않기 위한 단순화, 사용자가 "한꺼번에 비교"라고 표현한 것과도 부합).
   - `cumulative_prior_average(db, team, product_group, year, month, column="actual_amount")`에 `column` 매개변수를 추가해 `avg_unit_price` 기준으로도 재사용한다(기존 함수를 없애지 않고 일반화 — pl_comparison.py의 `_sum_refined`가 이미 쓰는 것과 같은 패턴).
3. `app/services/analytics.py`의 `get_anomalies`: 단가변동 플래그에 한해 `cumulative_before_value`(누계평균 평균단가) 필드를 추가로 채운다(전월 비교는 기존 `before_value`/`after_value` 그대로 사용).
4. `app/services/report_analysis_mapper.py`: `METRIC_CUMULATIVE_AVG` 관련 매핑을 제거하고, `METRIC_UNIT_PRICE`에 `ytd_change_pct`(누계평균 대비 %)를 채워 F7 문장에도 반영한다(comment_generator.py의 기존 YTD_CLAUSE를 그대로 재사용 — 필드/문구 자체는 그대로 두고 용도만 "단가변동의 누계 비교"로 다시 맞춘다).
5. 프론트 `app/anomalies/page.tsx`: `describeFlag`의 "단가변동" 분기를 사용자 예시 형식으로 재작성한다 — "{팀} · {제품군} — 당월 평균단가 A원, 전월 B원(C원, D% 차이), 누계평균 E원(F원, G% 차이)"(전월/누계 데이터가 없으면 그 부분만 "비교 불가"로 표시, 0으로 대체하지 않음).
6. `.docs/02_prd.md` F3 표에서 "누계평균대비" 행을 빼고 "단가변동" 설명에 전월+누계 통합 판정을 반영한다.

**범위 밖**:
- 매출액의 누계평균 비교는 완전히 폐지한다(다른 지표로 이전하지 않음).
- 전월/누계 각각 별도 임계치를 F6에 추가하지 않는다(기존 단가변동 임계치 하나로 판정).

## 방법·완료 기준

- 팀×제품군의 평균단가가 전월 대비 또는 누계평균 대비 중 하나라도 임계치를 넘으면 "단가변동" 플래그가 하나 생기고, F5 화면에 당월/전월/누계 세 값이 함께 표시된다.
- F6 임계치 목록에 "누계평균대비"가 더 이상 보이지 않는다(7개 기준으로 복귀).
- 백엔드 전체 pytest, 프론트 lint·build·vitest 통과.
